1. EXECUTIVE OVERVIEW
------------------------------------------------------------------------
Sarathi Micron LLP (formerly styled under Sarathi Clay) is a premium 
Indian minerals exporter and manufacturer specializing in high-purity
China Clay, Kaolin, Calcined Clay, and Washed Clay. This application is a 
modern, highly interactive corporate website and administrative platform 
designed to showcase their products, processing infrastructure, quality 
control, global logistics, and handle direct business-to-business (B2B) 
export inquiries.


2. CORE TECHNOLOGY STACK
------------------------------------------------------------------------
The project is built using modern web development frameworks and libraries 
to achieve a responsive layout, premium dark-themed visual aesthetics, and 
real-time serverless backend integrations:

* Framework: Next.js (version 16.2.7) utilizing App Router conventions.
* Language: TypeScript (TS) for strict static typing.
* UI Library: React (version 19.2.7) & React DOM.
* Database & Backend: Supabase JS Client Client-Library (@supabase/supabase-js, version 2.106.2).
* Animation Engines: 
  - GSAP (GreenSock Animation Platform, version 3.15.0) and @gsap/react (version 2.1.2) for high-precision timeline-based animations.
  - Framer Motion (version 12.4.0) for responsive layout transitions, page fades, and interactive modal overlays.
* Scroll Management: Lenis (lenis, version 1.3.23) for smooth web scrolling and programmatical scroll-locking.
* Icons & Vector Assets: Lucide React (version 1.17.0) for standard vector icons.
* CSS Framework: Tailwind CSS (version 3.4.1) for utility-first styling.
* Font Families: 
  - Playfair Display (Serif) for headings and branding elements.
  - Inter (Sans-serif) for body text, lists, and numbers.

4. COMPLETE FLOW & SYSTEM PIPELINES
------------------------------------------------------------------------

A. CLIENT INQUIRY FORM PIPELINE
=========================================
1. The user visits the '/contact' page.
2. The user fills out the contact form containing:
   - Name (Mandatory)
   - Company (Mandatory)
   - Email (Mandatory)
   - Phone (Mandatory)
   - Industry Selection (e.g. Vitrified Tiles, Sanitaryware)
   - Product Selection (e.g. China Clay, Kaolin)
   - Message Text (Mandatory)
3. Upon clicking submit, a POST request is triggered to the serverless
   endpoint '/api/contact'.
4. The API endpoint checks that all mandatory fields are present.
5. The API interacts with the Supabase client, inserting the record
   into the 'inquiries' table.
6. The client receives a 201 Created response, and displays a success
   modal or state.

B. ADMINISTRATIVE DASHBOARD PIPELINE
=========================================
1. An administrator navigates to '/admin'.
2. The page prompts the administrator for an access passkey.
3. The administrator enters the administrative passkey: "sarathi2026".
4. The dashboard issues a GET request to '/api/admin/inquiries' with the
   passkey passed securely inside the "x-admin-passkey" HTTP Header.
5. The server checks that the passkey matches "sarathi2026".
6. If authorized, the route pulls all inquiry submissions from the 
   Supabase 'inquiries' table, ordered by 'created_at' descending.
7. The dashboard displays the entries in a table.
8. The administrator can:
   - Search inquiries via search inputs.
   - Filter inquiries by Product or Active Industry.
   - Export all inquiries to a CSV file downloadable directly.
